# 產品規格書 — 單字練習台 v2

本文件定義畫面、流程、規則與資料格式。排程規則的數值全部承襲 v1，理由見 `01_PRD.md` 與 README「設計決策」。

## 0. 角色與權限

| 角色 | 入口 | 能做 | 不能做 |
|---|---|---|---|
| 學生 | 手機優先，底部 5 分頁 | 練習、看文章、加入班級、選公用教材、備份 | 看別人的進度、改講義 |
| 老師／家長 | 桌機優先，左側 4 項（儀表板、講義、班級、教材庫） | 建班、邀請、上稿、發布、設上課日、看所屬班級學生的彙總與進度、指派公用教材 | 讀學生備份內容、改學生的練習設定 |
| 開發者 | 老師介面＋教材庫管理 | 維護公用教材、v2.0 代老師上稿 | |

登入：**不強制**（App Store 5.1.1）。啟動直接進訪客的「今日」，資料存本機；加入班級、跨裝置同步、老師身分時才登入（Google／LINE／Apple，iOS 必備 Apple）。登入時把訪客的本機進度併入帳號（每張卡取 updatedAt 較新者）。首次登入選角色；同一帳號可兼老師與家長身分。訪客的「加入班級／登入同步」提示只在前三天顯示於今日卡片，之後收進設定。

班級模型：`teachers/{uid}` → `classes/{cid}`（邀請碼、預設讀書日與方案）→ `members`；`lessons/{lid}`（屬於老師，發布到一或多個班級，含字組、文章、音檔路徑、上課日）；學生進度在 `users/{uid}/…`，老師對所屬班級學生有讀權限。原文 PDF 存 `classes/{cid}/private/`，永不公開。

## 1. 資訊架構

```
啟動 → 今日（訪客，直接可練）
├── 需要時登入（加入班級／設定的帳號區／我是老師）
├── 學生：加入班級（代碼）→ 講義自動出現 → 主畫面（底部 5 個分頁）
└── 老師：建立班級 → 老師首頁（儀表板／講義／班級／教材庫）

學生主畫面
    ├── 今日        三段式練習
    ├── 字庫        依熟悉度／字組篩選，點開看卡片
    ├── 文章        閱讀＋跟讀（P2）
    ├── 行事曆      未來 30 天到期數、逾期
    └── 設定        教材選擇、額度、作答方式、聲音、帳號與同步、備份、重置
```

教材切換放在「設定」而不是主畫面，因為一位學生大多數時候只練一套；切換是低頻操作。

## 2. 核心流程：今日練習

```
buildQueue()
  到期複習（due ≤ 今天，依退步次數多→少、到期早→晚排序，取前 revCap）
  ＋ 新字（未學過，依教材順序，取前 goal）
→ 逐題：
  未學過的字：預習（顯示例句、音節拆解、手打一次）→ 回想 → 標記
  學過的字　：直接回想 → 標記
→ 標記後：
  ○　box +1、ease +0.10（上限 2.9）
  △　box −2（下限 0）、ease −0.15（下限 1.3）、reps>1 則 lapses +1
  ×　box = 0、ease −0.30（下限 1.3）、reps>1 則 lapses +1
  due = snap(今天 + max(1, round(LADDER[box] × ease / 2.5)))
       snap：若落在休息日，順延到下一個讀書日（最多往後找 14 天）
  同場回籠：非 ○ 且該字本場回籠 < 2 次 → × 插到 4 題後、△ 插到隊尾
```

### 排程方案（v1.2 起，v2 承襲）

| id | 名稱 | 間隔（天） | 自適應 | 跨度 | 適合 |
|---|---|---|---|---|---|
| mix | 考前混合（預設） | 1,1,1,1,7,15,30,60 | 是 | 116 | 學測、四個月以上 |
| f16 | 固定 16 遍 | 1,1,1,1,1,2,2,3,3,7,7,7,7,7,10,10 | 否 | 70 | 起步者、國中小 |
| f10 | 固定 10 遍 | 1,1,1,1,1,7,7,7,30,30 | 否 | 86 | 英檢初級、多益 600 |
| f8 | 固定 6–8 遍 | 1,1,1,1,7,7,30,30 | 否 | 78 | 英檢中級、多益 700 |
| e5 | 經典 5 遍 | 1,2,3,8,15 | 否 | 29 | 一個月一輪、每天固定量（艾賓浩斯經典表：第 2、4、7、15、30 天） |
| s8 | 衝刺 8 週 | 1,1,1,1,7,7,15 | 是 | 33 | 剩兩到三個月 |
| s4 | 衝刺 4 週 | 1,1,1,1,7 | 是 | 11 | 剩一個月內 |

- box 到達 `ladder.length - 1` 視為畢業，之後以最後一格的間隔持續複習
- 前段長度 `earlyLen` = 階梯開頭連續 1 的個數（4 或 5）
- 自適應方案：○ box+1、ease+0.10；△ box−2、ease−0.15；× box=0、ease−0.30；間隔 = ladder[box] × ease / 2.5
- 固定遍數方案：○ box+1；△ box 不變（同格再走一次）；× box−1；不用 ease
- 切換方案時保留每個字的 box，之後的間隔改查新階梯
- 目標日建議：跨度 ≤ 剩餘天數 × 0.9 的最長方案；沒有則衝刺 4 週

### 同場再看

- 答錯（△×）：既有規則，× 插到 4 題後、△ 插到隊尾，每字每場最多兩次
- 答對的**新字**（第一次作答）：排到隊尾再看一次；第二次答對只記錄，不推進 box、不改到期日；第二次答錯照一般規則處理但不計退步

### 讀書日與前段

- `strictEarly`（預設開）：box < earlyLen 的字到期日照日曆天，不順延；休息日打開 App 只出這些字，並顯示預估分鐘數
- 關閉時：所有到期日都順延到下一個讀書日，休息日不排任何進度

### 拆字與同字根（v1.3）

- `MORPH` 表：word → `'pre-|前;cept=cap|抓;-ion|名詞'`。form 結尾 `-` 為字首、開頭 `-` 為字尾、其餘為字根；`form=key` 把不同拼法歸到同一字根群。人工整理，只收有把握的分析
- 預習卡與對答案卡：音節拆解下方顯示「拆字」與「同字根」（字庫裡同鍵的字，最多 8 個，標未學）。回想卡不顯示，避免洩漏字義
- 字庫篩選「依字根／字尾分組」：字根群（≥2 字）→ 字首 → 字尾，每群一個可展開列
- `groupRoots`（預設開）：挑新字時，同字根的未學字拉到相鄰位置，不超過每日額度
- v2 教材包：拆字資料放在卡片的 `morph` 欄位，同一格式

### 音檔（v1.4）

- 內建：`audio/w/<slug>_<accent>.mp3`（單字）、`audio/s/<slug>_<accent>.mp3`（例句）、`audio/a/<artId>_<accent>.mp3`（整篇）、`audio/a/<artId>_s<n>_<accent>.mp3`（逐句，分句規則與 App 相同）。accent ∈ en-US / en-GB / en-AU / en-CA
- 產生：`tools/gen_audio.py`（神經網路語音，四國口音各一個女聲），ffmpeg 壓成 32 kbps 單聲道（文章 48 kbps）
- 播放：`sayAudio(kind,key,txt)` 先放 mp3，`onerror`（404、離線）退回 `speak()` 瀏覽器語音；速度跟設定的語速
- 文章流程（v1.4.1）：打開文章先只有播放器與「第一遍 · 先聽不看文字」提示，內文隱藏；音檔播到底 `onended` 才啟用「看文章對照」並累計 `read[id].listens`；可「直接看文章」跳過。看文章後才有再聽一次、逐句跟讀、理解題。**沒有計時按鈕**：`reveal()` 記 `rd.t0`，`finishArt()` 算 wpm（含點中譯與跟讀時間，第一次偏低是基準線），仍記最佳與重讀排程
- 逐字反白（v1.5.1）：`gen_audio.py` 用 `boundary='WordBoundary'` 串流取得每字 offset／duration，存 `<id>_<accent>.words.json`（[起秒, 迄秒, 文字]）；App 的 `bodyHTML` 把每個字包成 `.tw[data-i][data-s]`，`alignWords()` 依序正規化配對（實測 100% 對齊），`karaTick()` 用 requestAnimationFrame 二分搜尋當前字，加 `.lit`，同句加 `.lit-s`，超出視窗則 scrollIntoView。自己上傳的音檔沒有時間點，不反白
- 逐句中譯（v1.5.2）：`ARTZH[artId][k]` 人工翻譯，句序與 `rd.sens` 一致（建檔時 assert）。`bodyHTML` 每句包 `.sen[data-s]`，點句展開 `.senzh`（一次一句；點 `.kw` 不觸發），記錄 `read[id].zhOpened[k]`。「全部中譯」在 `finishArt` 後才啟用。v2 教材包：文章的 `sentences_zh` 陣列
- 文章頁：`<audio controls>` 播放器；「用自己的音檔」把檔案存進 IndexedDB（`vocab_audio/own`，key = 文章 id，上限 60 MB），優先於內建；可移除
- v2：音檔路徑寫進教材包（`audio` 欄位或約定命名），Flutter 用 just_audio 播放，PWA 快取常用音檔

### 每週講義與字組上課日（v1.6）

- 貼上字卡：`deck = 來源名稱`（原本全部進「匯入字卡」），字組開關自動出現
- `S.deckDue[deck] = 'yyyy-mm-dd'`；`deckDue(n)` 只在日期 ≥ 今天時有效
- `buildQueue` 挑新字：先依 `deckDue` 由近到遠，再 `pin`，再字組原順序；仍受每日額度限制
- 字組列顯示「上課日 · 還有 N 字，M 個讀書日，每天約 X 個」，X > goal 時警示；今日卡片列出所有有效上課日的字組
- 「過一遍」：字庫篩選 `deck:<name>`，依字組原順序列出，不排序、不影響排程
- 預習：`LESSON_ARTS[deck]` 對應文章；`previewItems()` 算預習日 = 上課日前一天，往前找最近的讀書日（已過則今天）。今日卡片與行事曆在該日多一項「上課前預習」，不影響 `artPlan` 的一般輪序與重讀
- 不做「只練這組」：會暫停其他字組的複習
- v2：教材包的 deck 加 `lesson_date`，profile 層可覆寫

### 找出生字（v1.5）

- 比對順序：字庫（含 `base()` 變化形）→ `data/dict.json`（`w` 字→[中文, 詞性]，`l` 變化形→原形）→ 空白（可線上查）
- 字庫已有：顯示熟悉度標籤；未學者可勾選，`pin=true`；`buildQueue` 挑新字時 pin 者優先，仍受每日額度限制
- 新字：建卡時 `deck='我的文章'`、`kind='r'`、`pin=true`、例句為文章原句、`exz` 選填
- 線上查：免費翻譯 API（`langpair=en|zh-TW`），回傳含 QUERY LENGTH／LIMIT 視為失敗
- 字典來源：開源英漢字典（MIT，見 THIRD_PARTY_NOTICES.md）取有考試標籤或語料庫前 15,000 的純小寫字，簡轉繁，每字最多兩個詞性、各三個義項

### 回音練習（v1.7）

- 需要內建音檔的逐字時間點；`echoChunks()` 依 `.tw` 順序切段：滿 6 字、或 ≥4 字遇標點、或句尾就斷，<3 字的尾巴併入前一段（上限 8 字）
- 每段四步：`echoPlay` 用 `currentTime` 播 s−0.06 到 e+0.12 → 停 1.5 秒（聽回音）→ 模仿（max(1.5s, 字數×0.52s)）→ 再播；三輪後停下等使用者按「再一次」或「下一段」
- 面板顯示段數、輪數、計時；十分鐘自動結束；`read[id].echoAt` 記錄段數、`echoMin` 累計分鐘
- 內文加 `.echo` 時其他字淡出，當前段 `.ech` 反白
- 單字跟讀與逐句跟讀改為四步：聽 → 停 1.5 秒 → 唸 → 再聽

### 任務系統（老師指派，v2.0）

把老師的紙本「每周在家學習進度表」數位化：**老師建立一週任務表 → 學生每天做完自動打勾填日期 → 老師看到同一張表**。一列一種任務，一格一天，休息日打 X；「不可跳格」由系統保證：前一天沒做的項目以「補做」顯示。

六種任務類型：

| 類型 | 老師設定 | 學生動作 | 完成判定 | 證據 |
|---|---|---|---|---|
| 課前聽 | 單元（預設下一堂講義）、每天幾軌（2）、開始日（上課前 8 週）、目標遍數（5） | 整軌播完，可邊聽邊跟 | 每軌播到底計一次 | 遍數 |
| 課後立即聽 | 單元（正在上的） | 上課日當天播一遍 | 播到底 | 系統紀錄 |
| 跟述三部曲 | 單元、每天幾軌（2）、是否錄音 | ① 只聽 ② 回音練習（看文字） ③ 不看文字跟述並錄音 | 三步完成 | 錄音檔 |
| 單字 | 每日新字、複習上限（沿用排程） | 現有練習 | 業績達成 | ○△× |
| 聽寫 | 軌（老師挑或系統建議）、次數上限（3） | 逐句聽、打整句、逐字比對 | 全部句子送出 | 正確率、漏字清單 |
| 課外閱讀 | 每天頁數（10／20）、是否朗讀錄音 | 填書名、頁數、上傳一頁朗讀；不查字典 | 頁數達標＋錄音 | 錄音、書名 |

| 外部英聽 | 每週幾集、素材清單（老師在班級設定維護：節目名或連結） | 填來源與集數；勾 ① 不看字幕聽大意 ② 開字幕找沒聽出來的字 ③ 口說摘要三句並錄音（可略） | ①② 勾選；③ 錄音 | 錄音、來源 |

另有「自由任務」：老師輸入文字，學生勾選，可拍照。外部英聽的素材由 App 外的平台播放，App 只記錄與收錄音，不代管內容。

- 單元＝講義（lesson），軌＝文章（article）。系統依上課日自動分「已上過／正在上／下一堂」，課前聽指向下一堂，聽寫與跟述只能挑已上過的
- 老師端：任務表**範本**（建一次，每堂課套用到新的一週）、指派到班級或個別學生並可調量、本週表（同紙本格子，點格看證據）、儀表板加本週完成率與聽寫正確率
- 學生端：今日卡片改成任務清單（每項有進度與「去做」）、本週表、錄音上傳
- 任務系統不改排程引擎，是架在既有功能上的清單與勾選層

### 逐句聽寫（v2.0，任務系統的一種）

- 用逐句 mp3：播一句（最多 3 次，可慢速）→ 打整句 → 逐字比對（正規化大小寫與標點）→ 標出漏字、錯字、多字
- 一篇做完顯示正確率與漏字清單；漏字若是字庫字，可一鍵排入下一批；漏掉的句子可直接跳到回音練習
- 記錄 `read[id].dictation = {date, acc, missed[]}`

### 每日業績

- `doneDays`：有作答的日期集合，起始日 = 最早的一天
- 今日卡片顯示：第 N 個讀書日、連續天數（休息日不斷鏈）、新字與複習各完成幾個、達成打勾
- 行事曆摘要顯示累計讀書日與連續天數

### 讀書日

每位學生設定一週哪幾天讀書（預設二三四五，至少一天）。所有到期日（單字、文章重讀）都經過 `snap` 順延；休息日打開 App 顯示「今天是休息日」而不排進度。行事曆的休息日列淡化顯示，新字預估只算在讀書日。每週實際新字量 = goal × 讀書日天數，UI 要明示這個數字。

### 作答方式

| 模式 | 規則 |
|---|---|
| auto（預設） | kind = r → choice；lapses ≥ 2 → spell；box ≥ earlyLen 且 reps % 3 == 0 → spell；其餘 choice |
| choice | 挖空例句＋四選一。干擾項優先同教材同詞性，其次同教材，其次首字母相同且長度相近 |
| spell | 手打完整單字，Levenshtein 距離 ≤ 1 視為 △ 候選 |
| dictate | 聽寫打字：只播例句，不給中文與挖空句，打出目標字；判定同 spell。由設定 `spellByEar` 把 spell 轉成 dictate，不是獨立模式 |

### 學習計畫試算（設定頁）

改任一輸入（每日新字、讀書日、方案、目標日、字組開關）即時更新：起始日與累計讀書日、字庫（未學／學習中／畢業）、每週新字、新字學完日（依讀書日逐日數）、全部畢業預估（學完日 + 方案跨度，順延到讀書日）、每日負擔（新字 + 未來兩週讀書日平均複習）、一個字的旅程（由階梯產生的文字）、目標反推（每日至少幾個、建議方案、一鍵套用）。

## 3. 帳號與學生

- 一個登入帳號＝一位學生（或一位老師）。家長替孩子用：家長建一人班，孩子用自己的 LINE／Google 登入
- **進度以「字」為單位、跨教材共用**：同一個字（以原形 lemma 為鍵）不論出現在學測、英檢講義或自己貼的卡，都只有一筆進度，不會因為同時開兩套教材而複習兩次。教材只是「引用」這個字並附自己的例句；複習時顯示最近學過的那套教材的例句，其餘例句在字卡可切換
- 老師上稿時系統標出「這 N 個字已在公用教材或其他講義」，不重複建卡，但仍列入該講義的「過一遍」清單與上課日優先（未學者）
- **班級講義與公用教材可同時開**（已定），每日額度共用，今日清單先講義後公用
- 登出保留本機資料；換帳號登入會另建本機資料
- 刪除帳號需二次確認，且先強制下載備份

## 3a. 老師端

- **儀表板**：本週卡（學生數、有練人數、平均連續）、講義卡（完成率、文章預習）、要注意（3 天沒練、本週退步 ≥10、講義每日需求超過上限）；學生表（連續、本週新字／複習、講義進度、文章、回音分鐘、最近）；點學生看細節（熟悉度分布、中譯點最多的句子、退步最多的字、**每個字的 ○△×**）
- **每個字的 ○△×（推導值）**：不是使用者最後一次點的標記，而是由累積紀錄算出的狀態，規則：
  - × 生疏：`lapses ≥ 2`，或最近 5 次作答有 2 次以上 ×，或 box = 0 且 reps ≥ 2
  - △ 卡點：不符 × 且（box < earlyLen，或最近 5 次有 △／×，或 lapses = 1）
  - ○ 穩定：box ≥ earlyLen 且最近 5 次全 ○ 且 lapses = 0
  - 未學：seen = false
  - 儀表板可依這個狀態篩選（例如列出某講義所有 × 的字），也是「退步最多」的來源。引擎提供 `derivedMark(progress, recentLog)` 純函式，App 與儀表板共用
- **上稿（三步）**：① 上傳 PDF／貼文字（掃描檔提示改貼文字）② 審核字卡：抽字（字庫比對＋字典），勾選、改中文、P／R、例句（v2.1 可 AI 產）③ 文章（貼原文僅班級可見，或 AI 改寫）、題目、逐句中譯、產音檔（伺服器，四國口音＋逐字時間點）、設上課日、發布到班級
- **班級**：改名、邀請碼、LINE 分享連結、預設讀書日／每日新字／方案、成員名單與移出
- **教材庫**：我的講義（草稿／已發布）、公用教材（指派給班級）
- 發布後可修改，學生端下次啟動更新，已學進度不受影響

## 4. 教材包（Course Pack）

### 目錄 `data/courses.json`

```json
{
  "version": 1,
  "courses": [
    { "id": "gsat",      "name": "學測",     "exam": "gsat",  "level": "高中",   "file": "courses/gsat.json",      "words": 749 },
    { "id": "gept-int",  "name": "英檢中級", "exam": "gept",  "level": "中級",   "file": "courses/gept-int.json",  "words": 0 },
    { "id": "self-study", "name": "自學教材",   "exam": "other", "level": "自學",   "file": "courses/self-study.json", "words": 0 }
  ]
}
```

`exam` 列舉：`gsat`、`gept`、`toeic`、`toefl`、`ielts`、`elementary`、`junior`、`other`。UI 依 `exam` 分群、依 `level` 排序。

### 教材 `data/courses/<id>.json`

```json
{
  "id": "gsat",
  "name": "學測",
  "version": "2026-09-09",
  "decks": [
    {
      "id": "l34",
      "name": "學測 L3–4 高頻字",
      "defaultKind": "p",
      "cards": [
        {
          "id": "b0",
          "en": "abandon", "pos": "v.", "zh": "放棄；拋棄",
          "ex": "They abandoned the plan.", "exz": "他們放棄了那個計畫。",
          "form": "abandoned", "note": "", "syl": "aban·don", "fam": ["abandonment"], "kind": "p",
          "morph": "ab-|離開;band|禁令"
        }
      ]
    }
  ],
  "articles": [ { "id": "a1", "title": "...", "level": "英檢中級", "tag": "...", "body": "...", "questions": [] } ],
  "sources": [ { "id": "s0", "name": "...", "file": "...", "date": "2026-08-19", "note": "..." } ]
}
```

- `id` 在教材內唯一且**永不改變**，進度靠它對應。gsat 教材沿用 v1 的 `b<i>`、`d<deck>_<i>` 編號，讓 v1 備份可直接對應
- `kind`：`p` 要會拼寫、`r` 看得懂就好；卡片沒填則用 deck 的 `defaultKind`
- 卡片欄位除 `id`、`en`、`zh` 外皆可省略

### 八欄文字格式（給 AI 與人工整理用，與 v1 相同）

```
單字 | 中文 | 詞性 | 英文例句 | 例句中譯 | 用法筆記 | 音節拆解 | P或R
```

`tools/cards2json.dart` 負責轉成上面的 JSON，並檢查：單字不重複、id 不與既有衝突、例句包含該字或其變化形。

## 5. 進度資料

每（帳號 × 字）一筆，鍵為 lemma；教材與卡片透過 lemma 對應到同一筆：

```
cardId, box, ease, reps, lapses, streak, seen, due(yyyy-mm-dd), last(yyyy-mm-dd),
kindOverride(p/r/null), updatedAt(ISO, 同步用)
```

作答紀錄另存 `review_log`（append-only）：`cardId, date, mark(o/t/x), mode, elapsedMs`。v1 只留最近 14 筆，v2 全留，行事曆與統計靠它。

自訂字卡（使用者在裝置上貼的）存在檔案層，內容與進度都在本機／雲端，不進教材包。

## 6. 備份與匯入

- **匯出**：`{ format: "vocab-trainer-backup", version: 2, profile, courses: { <courseId>: { progress, customCards, log } }, settings }`
- **匯入 v1**：讀 `version: 1` 的 `state.recs`，id 以 `b`、`d` 開頭者對應 gsat 教材；以 `u` 開頭者轉成自訂字卡；`state.sources` 中 `own: true` 者一併帶入；`goal`、`revCap`、`mode`、`rate` 進設定
- 匯入採**合併**而非覆蓋：同一張卡取 `updatedAt`（v1 用 `last`）較新者

## 7. 同步（P0）

- 登入方式：Google、LINE（Cloud Function 驗證 LINE access token 後簽發 Firebase custom token）、Apple
- Firestore 結構：`users/{uid}/words/{lemma}`（跨教材共用的進度），`review_log` 為子集合；教材卡片以 lemma 對應；`classes/{cid}`、`lessons/{lid}` 見第 0 節
- 離線優先：本機 Drift 為真相，Firestore 開離線快取；每筆寫入帶 `updatedAt`，衝突取新者
- 安全規則：`users/{uid}` 本人可寫；所屬班級的老師可讀 `progress` 彙總；`classes/{cid}` 老師可寫、成員可讀；`lessons/{lid}` 老師可寫、發布班級的成員可讀；`classes/{cid}/private` 只有老師
