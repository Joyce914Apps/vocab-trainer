# 產品規格書 — 單字練習台 v2

本文件定義畫面、流程、規則與資料格式。排程規則的數值全部承襲 v1，理由見 `01_PRD.md` 與 README「設計決策」。

## 1. 資訊架構

```
啟動
├── 選學生（首次：建立第一位）
└── 主畫面（底部 5 個分頁）
    ├── 今日        三段式練習
    ├── 字庫        依熟悉度／字組篩選，點開看卡片
    ├── 文章        閱讀＋跟讀（P2）
    ├── 行事曆      未來 30 天到期數、逾期
    └── 設定        教材選擇、額度、作答方式、聲音、帳號與同步、備份、重置
```

教材切換放在「設定」而不是主畫面，因為一位學生大多數時候只練一套；切換是低頻操作。

## 2. 核心流程：今日練習

```
buildQueue()
  到期複習（due ≤ 今天，依退步次數多→少、到期早→晚排序，取前 revCap）
  ＋ 新字（未學過，依教材順序，取前 goal）
→ 逐題：
  未學過的字：預習（顯示例句、音節拆解、手打一次）→ 回想 → 標記
  學過的字　：直接回想 → 標記
→ 標記後：
  ○　box +1、ease +0.10（上限 2.9）
  △　box −2（下限 0）、ease −0.15（下限 1.3）、reps>1 則 lapses +1
  ×　box = 0、ease −0.30（下限 1.3）、reps>1 則 lapses +1
  due = 今天 + max(1, round(LADDER[box] × ease / 2.5))
  同場回籠：非 ○ 且該字本場回籠 < 2 次 → × 插到 4 題後、△ 插到隊尾
```

`LADDER = [1, 1, 1, 1, 7, 15, 30, 60]`，box 超過 7 視為畢業。

### 作答方式

| 模式 | 規則 |
|---|---|
| auto（預設） | kind = r → choice；lapses ≥ 2 → spell；box ≥ 4 且 reps % 3 == 0 → spell；其餘 choice |
| choice | 挖空例句＋四選一。干擾項優先同教材同詞性，其次同教材，其次首字母相同且長度相近 |
| spell | 手打完整單字，Levenshtein 距離 ≤ 1 視為 △ 候選 |
| recog | 看例句想中文，翻面自評 |

## 3. 學生檔案

- 一台裝置可有多個檔案，啟動時顯示選擇畫面，記住上次選的
- 每個檔案：`id`、`name`、`createdAt`、`avatar`（可選）、`cloudUid`（已連結帳號時）
- 進度以（檔案 × 教材）為單位獨立，切換教材不影響其他教材的到期複習
- 刪除檔案需二次確認，且先強制下載備份

## 4. 教材包（Course Pack）

### 目錄 `data/courses.json`

```json
{
  "version": 1,
  "courses": [
    { "id": "gsat",      "name": "學測",     "exam": "gsat",  "level": "高中",   "file": "courses/gsat.json",      "words": 749 },
    { "id": "gept-int",  "name": "英檢中級", "exam": "gept",  "level": "中級",   "file": "courses/gept-int.json",  "words": 0 },
    { "id": "cheng-han", "name": "固定遍數法",     "exam": "other", "level": "自學",   "file": "courses/cheng-han.json", "words": 0 }
  ]
}
```

`exam` 列舉：`gsat`、`gept`、`toeic`、`toefl`、`ielts`、`elementary`、`junior`、`other`。UI 依 `exam` 分群、依 `level` 排序。

### 教材 `data/courses/<id>.json`

```json
{
  "id": "gsat",
  "name": "學測",
  "version": "2026-09-09",
  "decks": [
    {
      "id": "l34",
      "name": "學測 L3–4 高頻字",
      "defaultKind": "p",
      "cards": [
        {
          "id": "b0",
          "en": "abandon", "pos": "v.", "zh": "放棄；拋棄",
          "ex": "They abandoned the plan.", "exz": "他們放棄了那個計畫。",
          "form": "abandoned", "note": "", "syl": "aban·don", "fam": ["abandonment"], "kind": "p"
        }
      ]
    }
  ],
  "articles": [ { "id": "a1", "title": "...", "level": "英檢中級", "tag": "...", "body": "...", "questions": [] } ],
  "sources": [ { "id": "s0", "name": "...", "file": "...", "date": "2026-08-19", "note": "..." } ]
}
```

- `id` 在教材內唯一且**永不改變**，進度靠它對應。gsat 教材沿用 v1 的 `b<i>`、`d<deck>_<i>` 編號，讓 v1 備份可直接對應
- `kind`：`p` 要會拼寫、`r` 看得懂就好；卡片沒填則用 deck 的 `defaultKind`
- 卡片欄位除 `id`、`en`、`zh` 外皆可省略

### 八欄文字格式（給 AI 與人工整理用，與 v1 相同）

```
單字 | 中文 | 詞性 | 英文例句 | 例句中譯 | 用法筆記 | 音節拆解 | P或R
```

`tools/cards2json.dart` 負責轉成上面的 JSON，並檢查：單字不重複、id 不與既有衝突、例句包含該字或其變化形。

## 5. 進度資料

每（檔案 × 教材 × 卡片）一筆：

```
cardId, box, ease, reps, lapses, streak, seen, due(yyyy-mm-dd), last(yyyy-mm-dd),
kindOverride(p/r/null), updatedAt(ISO, 同步用)
```

作答紀錄另存 `review_log`（append-only）：`cardId, date, mark(o/t/x), mode, elapsedMs`。v1 只留最近 14 筆，v2 全留，行事曆與統計靠它。

自訂字卡（使用者在裝置上貼的）存在檔案層，內容與進度都在本機／雲端，不進教材包。

## 6. 備份與匯入

- **匯出**：`{ format: "vocab-trainer-backup", version: 2, profile, courses: { <courseId>: { progress, customCards, log } }, settings }`
- **匯入 v1**：讀 `version: 1` 的 `state.recs`，id 以 `b`、`d` 開頭者對應 gsat 教材；以 `u` 開頭者轉成自訂字卡；`state.sources` 中 `own: true` 者一併帶入；`goal`、`revCap`、`mode`、`rate` 進設定
- 匯入採**合併**而非覆蓋：同一張卡取 `updatedAt`（v1 用 `last`）較新者

## 7. 同步（P1）

- 登入方式：Google，或匿名＋六位代碼（代碼可在另一裝置輸入以認領同一份資料）
- Firestore 結構：`users/{uid}/profiles/{pid}/courses/{cid}/cards/{cardId}`，`review_log` 為子集合
- 離線優先：本機 Drift 為真相，Firestore 開離線快取；每筆寫入帶 `updatedAt`，衝突取新者
- 安全規則：只有 `request.auth.uid == uid` 可讀寫

## 8. 設定項

| 項目 | 預設 | 範圍 |
|---|---|---|
| 每日新字 goal | 12 | 3–60 |
| 每日複習上限 revCap | 60 | 10–200 |
| 作答方式 mode | auto | auto / choice / spell / recog |
| 語速 rate | 0.85 | 0.6 / 0.85 / 1.0 |
| 進新字自動朗讀 | 開 | |
| 文章間隔 artEvery | 3 天 | 1–14 |
| 字體大小 | 17 | 14–22 |
| 主題 | 跟隨系統 | 亮 / 暗 / 系統 |

## 9. 無障礙與裝置

- 最小可用寬度 360px；選項按鈕高度 ≥ 44px
- 鍵盤：Enter 送出／下一步，1–4 選項，○△× 對應 1 2 3
- 深色模式跟隨系統
- 所有文字可放大到 22px 不破版
