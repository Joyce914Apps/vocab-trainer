# 設計簡報（給 Claude Design 出 mockup 用）

日期：2026-09-11。每次請 Claude Design 出圖，把本文件加上指定的線框頁與規格段落一起給它。產出交回 RD 前由 PM 依第 6 節驗收。

## 1. 產品一句話

給準備考試的高中生與自學者的英文單字練習 App：三段式練習（認識、回想、自評），間隔重複排程，文章先聽再看，回音練習；老師可建班、上稿、看進度。Flutter Web／Android／iOS 同一套，手機優先，老師端桌機優先。

## 2. 使用者與場景

- 學生：高三，舞蹈班，每週約 8 小時讀書時間，多在晚上用手機、累的時候用。需要「打開就能做、不用想」的介面，字要大、按鈕要大、一次只做一件事。
- 老師／家長：桌機或平板，每週一次上稿與看進度，需要表格與一眼看完的摘要。
- 環境：通勤、睡前、舞社休息室；單手操作；常戴耳機。

## 3. 設計原則（按優先序）

1. **專注**：練習卡畫面上只有這張卡，沒有其他干擾；導覽在需要時才出現。
2. **可讀**：內文用襯線體（例句、文章），介面用無襯線；字級可縮放 14–26；行高寬鬆。
3. **可愛但不吵**：品牌是可愛的手繪風（見第 4 節），但只出現在有身分的地方（icon、啟動、登入主視覺、引導卡小圖、空狀態小角色、業績達成的一個小圖）；練習卡、文章、表格、設定保持乾淨，沒有插圖。
4. **誠實**：不用「加油」「太棒了」這類話；文案就是線框裡的那些句子，直述、短。
5. **深色模式**是必要的，睡前用；對比要過 WCAG AA。
6. **一致**：同一個動作在每個畫面長一樣（例如 🔊 永遠在音節旁、○△× 永遠三顆並排）。

## 4. 視覺風格：可愛的手繪風（所有作品統一）

- **風格參考**：`docs/design/brand/reference_bento_icon.png`（訂便當 App 的 icon）。粗深色描邊、圓潤 Q 版、擬人化小臉與腮紅、粉彩配色（奶油黃底、粉紅、番茄紅、蛋黃、萵苣綠、海苔墨綠）、少量星星愛心、淡色圓形底。要求「同一位插畫家的筆觸」。
- **本作品的主題物件**：字卡與耳機（或一隻戴耳機、拿字卡的小角色），用來做 icon、啟動畫面、引導卡小圖、空狀態。
- **介面色彩 token 從 icon 的粉彩取**：主色粉紅或蛋黃擇一；○＝萵苣綠、△＝琥珀、×＝番茄紅；反白＝蛋黃；深色模式底用海苔墨綠系或深灰，保留同一組粉彩作強調。
- **字體**：介面 PingFang／Noto Sans TC；例句與文章用 Iowan Old Style／Georgia 一類的襯線；數字與日期用等寬。
- **不要**：現行網頁版的紙感米白風、漸層、3D、寫實插圖、遊戲化徽章、超過三種強調色。
- **個人簽名**：GitHub 頭像（黑底雙圓框手寫「J」，`docs/design/brand/avatar.png`）用原檔不重畫；放在關於頁、啟動畫面右下角、商店開發者圖、PDF 封面、README 頂部；單色版、最小 24px、留白一個圓的半徑；不放進練習內容與老師端表格。
- 跨作品的完整規則：`914Apps/BRAND.md`。

## 6. 給 Claude Design 的指示範本

```
請依 docs/09_設計簡報.md 的原則，畫「D1-3 練習卡」這一組：
- 依線框第 9 頁的三張畫面（預習、回想－選擇、對答案）加上「回想－拼寫」「回想－聽寫打字」
- 尺寸：手機 390×844（iPhone）直式；每張畫亮色與深色
- 狀態：對答案要畫 ○／△／× 三種建議被選中的樣子；拼寫要畫「給我提示」展開後
- 文案用線框上的字，不要改；○△× 三顆按鈕的說明文字要顯示下次間隔
- 用 docs/design/tokens.json 的色彩與字級
- 輸出：每張一個 artboard，命名 D1-3-預習、D1-3-回想-選擇 …；另附一頁標註可點區塊與間距
不要：練習卡上放插圖、漸層、慶祝動畫、超過三種強調色。手繪小圖只在引導卡與空狀態。
```

## 7. 產出格式與驗收

- 每組交：artboard（亮／深）、標註頁（間距、字級、元件名稱）、若有新元件則更新 tokens 與元件清單。
- 驗收清單：文案與線框一致；○△× 與螢光色只用在該用的地方；深色對比過 AA；手機單手可及（主要按鈕在下半部）；狀態齊全（預設／載入／空／錯誤／離線）；沒有品牌或人名。
- 交付路徑：`docs/design/<組別>/`，PNG 加上 Claude Design 的 canvas 連結記在 `docs/design/README.md`。
