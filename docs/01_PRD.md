# PRD — 單字練習台 v2（Flutter）

版本：2026-09-10 修訂 2（加入角色與登入）　｜　狀態：規劃中，預計 W2–W4 課餘時間開工　｜　v1（HTML）已上線：https://joyce914apps.github.io/vocab-trainer/

## 1. 背景與問題（Why）

v1 是為一位準備學測的高中生做的單一 HTML 工具，到 v1.7 已驗證的設計（v2 全部承襲）：三段式練習（預習→挖空回想→○△×）、前段連續的間隔階梯與七個可選方案、讀書日與前段不順延、拆字與同字根、四國口音內建音檔、文章先聽再看與逐字反白、逐句中譯、回音練習、每週講義的字組上課日與預習、找出生字的字典自動帶入。

但 v1 有四個結構性限制，改 HTML 解決不了：

1. **進度綁在一台裝置的一個瀏覽器**。換手機、換電腦、清瀏覽資料，進度就分家或消失。只能靠手動備份檔。
2. **只有一個學生**。第二位使用者要用，只能開另一個瀏覽器。
3. **教材寫死在程式裡**。新增一份講義要改 JavaScript 陣列。學測、英檢、TOEIC、國中小、自學教材沒辦法各自成套、各自選程度。
4. **排程邏輯沒有測試**。它是產品的核心，但目前只能靠人工試。

## 2. 目標與非目標

**目標**

- G0　兩種角色分流：學生（手機優先，練習）與老師（桌機優先，建班、上稿、發布、看進度）。**不強制登入**（App Store 5.1.1）：訪客可完整練習，加入班級、跨裝置同步、老師身分時才登入（Google／LINE／Apple），訪客進度併入帳號
- G1　同一個學生在手機、電腦、平板打開都是同一份進度，離線也能練，連線自動同步
- G2　學生可加入多個班級；每位學生在每套教材各有獨立進度
- G3　教材做成資料包，新增教材不改程式；每套教材有自己的考試類別與程度
- G4　排程引擎是純 Dart 套件，有完整單元測試，參數與理由寫在文件裡
- G5　v1 的備份檔可以直接匯入，舊使用者不掉進度
- G6　Flutter Web 先上線取代 v1；之後加 Android 只是多一個 build 目標

**非目標（v2.0 不做，v2.1 做）**

- 老師自助上稿與 AI 產例句／改寫／題目／中譯（v2.0 由開發者在同一介面代做，老師只審核與發布）
- LINE 推播提醒（v2.1）

**非目標（v2 都不做）**
- LINE / LIFF 入口與推播（見 ADR-0003，與 line_bento_order 重複，不做）
- 自動從 PDF 產生字卡（轉檔工具只吃已整理好的八欄文字）
- 社群、排行榜、付費

## 3. 目標使用者與情境

| 使用者 | 情境 | 需要 |
|---|---|---|
| 準備學測／英檢的高中生（主要） | 平日晚上 30–60 分鐘，週末只有零碎時間，常在手機上練 | 開了就能練、離線可用、進度不會丟、老師的講義自動出現 |
| 老師／家教／家長 | 每週一份講義，桌機上處理；想知道誰沒練、誰卡住 | 上稿快、發布後學生端自動排、儀表板一眼看完 |
| 準備 TOEIC／TOEFL／IELTS 的成人自學者 | 通勤時用手機，回家用電腦 | 跨裝置同步、能自己加教材 |
| 國中小學生 | 家長或家教陪同，用家裡共用的平板 | 同一裝置切換學生、介面字大 |
| 教材整理者（目前是開發者本人） | 拿到講義後把單字整理成字卡 | 有明確的資料格式與轉檔工具 |

## 4. 使用者故事（核心）

- US1　身為學生，我在手機練完 20 個字，晚上打開電腦，複習行事曆顯示的是同一份進度。
- US2　身為家長，我在家裡平板上切換到弟弟的檔案，他的進度和姊姊的完全分開。
- US3　身為學生，我從「學測 L3–4」切換到「英檢中級」，兩套教材的到期複習分開計算，不會互相搶額度。
- US4　身為教材整理者，我把一份新講義轉成 JSON 放進 `data/courses/`，push 之後所有使用者下次開啟就看得到。
- US5　身為 v1 使用者，我上傳舊的備份檔，749 個字的熟悉度、複習日期、退步紀錄全部保留。
- US6　身為學生，沒有網路時我照樣練習，恢復連線後進度自動上傳，不需要按任何按鈕。
- US7　身為老師，我上傳講義後審核字卡、設上課日、發布，學生端隔天就排進去，不用我一個一個通知。
- US8　身為老師，我打開儀表板就知道誰三天沒練、誰在哪幾句卡住，可以在課堂上針對那幾句講。
- US9　身為家長，我替孩子建一個一人班，孩子用自己的 LINE 登入，我看得到他的進度但改不了他的練習。

## 6. 成功指標

- 排程引擎測試通過率 100%，且 v1 的排程行為在引擎測試中有對照案例（同輸入同輸出）
- v1 使用者匯入備份後，抽查 20 個字的 box／ease／due 與 v1 一致
- 手機瀏覽器首次載入 5 秒內可操作（4G），第二次 2 秒內
- 離線練習 50 題後恢復連線，30 秒內另一裝置看到更新
- 新增一套教材不需要改任何 Dart 程式碼

## 7. 風險與對策

| 風險 | 對策 |
|---|---|
| 搶走 stock_ledger 主線時間 | 只用 W2–W4 課餘；P0 做完就上線，P1/P2 排到 W8 之後 |
| Flutter Web 首次載入慢 | 用 `--wasm` 或 CanvasKit 擇優；教材 JSON 延遲載入；預設字體不內嵌 |
| 未成年使用者的帳號與個資 | 用 LINE／Google 登入，不自管密碼；只存暱稱與進度；老師只能讀所屬班級學生的彙總與進度，不能讀備份內容 |
| 教材版權 | 老師上傳的原文與 PDF 存在班級私有空間，永不進公開資料與 repo；只有 AI 改寫版（老師勾選同意）可進公用教材 |
| 後端與 AI 費用 | v2.0 後端只有 Auth、Firestore、LINE 驗證的 Function，免費額度內；v2.1 的 AI 按用量計費，一份講義數十元內，由老師端設定的金鑰或平台代付（待決） |
| 同步衝突 | 進度以「卡片」為單位，取最後作答時間較新者（LWW），不做合併；作答紀錄 append-only |
| 教材版權 | 例句改寫或自寫；雜誌文章一律原創改寫；教材包標明來源 |
| v1 與 v2 並存期混亂 | 上線當天 v1 移到 `legacy/`，Pages 只留 v2；v1 的網址自動導向 |
