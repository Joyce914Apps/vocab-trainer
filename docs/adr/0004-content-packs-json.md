# ADR-0004 教材做成 JSON 資料包

日期：2026-09-09　｜　狀態：已採納

## 背景

v1 的字組寫死在程式常數裡，新增教材要改程式碼。需求是支援學測、英檢、固定遍數法、TOEIC、TOEFL、IELTS、國中小等多套教材，各有考試類別與程度。

## 決定

教材與程式分離：`data/courses.json` 目錄 + 每套教材一個 JSON。App 啟動時載入目錄，選定教材後才載入內容。卡片 `id` 在教材內永不改變，進度靠它對應。gsat 教材沿用 v1 的 id 編號以相容舊備份。

## 理由

- 新增教材不改程式、不重新 build（Web 上只要 push 資料檔）
- 內容可由非工程師整理（八欄文字 + 轉檔工具）
- 進度與內容分離後，多學生、多教材的資料模型才乾淨
- 教材版本化（`version` 欄位），日後可做「教材更新但進度保留」

## 代價

- 教材不進資料庫，字庫搜尋在記憶體做；教材超過數千字時要考慮索引
- Web 上多一次網路請求（可用 PWA 快取解決）
- id 永不改變是紀律，轉檔工具必須檢查衝突
