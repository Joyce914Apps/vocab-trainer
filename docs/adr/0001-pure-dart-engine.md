# ADR-0001 排程引擎做成純 Dart 套件

日期：2026-09-09　｜　狀態：已採納

## 背景

v1 的排程邏輯（間隔階梯、難度係數、同場回籠、作答方式判斷）散在 HTML 的四個函式裡，沒有測試。它是產品的核心價值，也是作品集裡最值得展示的部分。

## 決定

引擎獨立成 `packages/srs_engine`，零 Flutter 依賴，所有函式純粹（時間由外部注入、不含隨機）。App 只負責組裝：讀進度、呼叫引擎、寫回、畫畫面。

## 理由

- 純函式不需要 mock，測試寫得快、跑得快
- 可以用 v1 的真實作答紀錄做對照測試，證明 v2 行為與 v1 一致
- 與 stock_ledger 的 portfolio_engine 同一種設計，兩個作品互相印證
- 未來若要在 Cloud Function 或其他平台重算排程，直接重用

## 代價

- 多一個套件要維護版本與相依
- App 層要多寫一層轉接（Drift 資料 → 引擎模型）
