# 單字練習台 使用說明（v1.7）

網址：https://joyce914apps.github.io/vocab-trainer/　手機、平板、電腦的瀏覽器都能開，不用安裝。進度存在**這台裝置的這個瀏覽器**裡，換裝置請看「備份」。

---

## 一、每天怎麼用（5 分鐘看懂）

1. 打開網頁，停在「**今日**」分頁。最上面的卡片告訴你今天要做什麼：新字幾個、複習幾個、有沒有文章、有沒有講義要預習。
2. 往下就是練習卡，照著做：
   - **① 建立印象**：第一次見到的字。看例句、聽發音、看拆字，把字**手打一次**，按「記住了，考我」。
   - **② 回想**：例句挖空，預設是四選一；也可能要拼寫或只求認得（看設定）。
   - **③ 標記**：程式會建議 ○△×，你可以改。○ 會了、△ 有卡點、× 不會。**你比程式清楚剛剛是真會還是矇到**。
3. 答錯的字幾題後會再出現一次，答對的新字當場最後再看一次。這是設計，不是重複。
4. 做到卡片說「今天的業績達成」就可以停。沒做完也沒關係，明天到期的字會自己排進來。

鍵盤：Enter 送出／下一步，1–4 選選項，○△× 對應 1、2、3。

## 二、五個分頁

| 分頁 | 用途 |
|---|---|
| 今日 | 每天的練習。頂端卡片是今天的清單與業績 |
| 字庫 | 所有字的熟悉度。可搜尋、篩選（生疏、退步過、今天到期、未學、已畢業、依字根／字尾分組、某個字組） |
| 文章閱讀 | 先聽再看的閱讀與跟讀（見第四節） |
| 複習行事曆 | 未來 30 天每天要複習幾個字、哪幾天休息、哪天有文章與講義預習 |
| 設定與備份 | 字組開關、每日新字、讀書日、方案、聲音、備份、重置（見第五節） |

另外「貼上字卡」分頁用來自己加字（見第六節），「教材來源」列出每份講義的字數與進度。

## 三、熟悉度與複習節奏

- 每個字有自己的「階」。答對升一階，下次出現的間隔變長；答錯退階，很快再出現。
- 預設節奏：新字**前四天每天出現**，之後隔 7、15、30、60 天。前四天是遺忘最快的區段，所以不順延、休息日也會露臉（只做這些字，約 5 分鐘）。
- 「已畢業」的字仍會每 60 天回來一次。
- 字庫每個字下面有小方塊，越多綠色越熟。

## 四、文章閱讀

1. 點一篇文章。先**只有播放器**，看不到文字。按播放，聽完一遍再按「聽完第 1 遍了，看文章對照」。想再聽幾遍都可以。
2. 看文章時，唸到的字會像螢光筆一樣**逐字反白**。看不懂的句子**點一下**出現中譯，再點收起。
3. 練發音有三種：
   - **回音練習**（建議）：4～6 個字一段。播 → **停，先別出聲，聽心裡留下的回音** → 照著回音唸 → 再播對照。同一段走三輪，溜了按「下一段」。每天十分鐘，時間到會自動結束，明天從那一段接著。
   - **逐句跟讀**：整句，聽 → 停 → 唸 → 再聽。
   - **錄音／播我的**：錄自己唸的，和原音比。
4. 讀完按「讀完了，看理解題」。答完題才能按「全部中譯」。閱讀速度（wpm）會自動算，不用按計時；第一次偏低是正常的，重讀那天的數字才是速度。
5. 每篇會排 4 天後、14 天後重讀。

**自己的音檔**：有老師的錄音可以按「用自己的音檔」上傳，只存在這台裝置，會優先播放，但沒有逐字反白與回音練習。

## 五、設定

- **字組**：勾選要練哪些。每週講義各是一組，旁邊填**上課日**，這組還沒學的字就會排到新字最前面，並顯示「還有 N 字、每天約 X 個」；講義的文章會在上課前一天出現「上課前預習」。**不要為了趕講義關掉其他字組**，複習會堆起來。按「過一遍」可以到字庫依講義順序看整組。
- **每日新字**：3–60。**讀書日**：勾一週哪幾天讀。**目標完成日**：填了會反推每日新字與建議方案。下方的「學習計畫試算」會即時算出學完日、畢業預估、每日負擔。
- **排程方案**：預設「考前混合」。另有固定 16／10／6–8 遍、經典 5 遍（第 2、4、7、15、30 天）、衝刺 8 週／4 週。換方案不會清進度。
- **作答方式**：自動（預設）／選擇／拼寫／只求認得。學測只有中譯英與作文需要拼得出來，所以預設選擇題。
- **聲音**：口音（美、英、澳、加，多益英聽四種）、語速、進新字自動唸。單字、例句、文章都是內建的神經網路語音，離線才退回瀏覽器語音。
- **A－ A＋**：整體字級。**深色**：切換主題。

## 六、加字

- **貼文章找生字**：把文章貼進「貼上字卡」按「找出生字」。字庫已有的字會標熟悉度，勾未學的按「排入下一批」；新字自動帶入中文，字典沒有的按「線上查」，例句用文章那一句，也可「翻例句」。
- **貼上字卡**：一行一張，`單字 | 中文 | 詞性 | 例句 | 例句中譯 | 用法筆記 | 音節 | P或R`，來源名稱就是字組名稱。
- 自己加的字沒有內建音檔，會用瀏覽器語音。

## 七、備份與換裝置

「設定與備份」→「下載備份檔」存成 JSON，到新裝置按「從檔案還原」。建議每週下載一次。手機不方便存檔可用「產生備份文字」複製。清除進度或完全重置前，先備份；那兩顆按鈕要按兩次才會執行。

## 八、常見問題

- **休息日打開沒東西？** 正常。到期的複習順延到下一個讀書日；只有前四天的新字會露臉。
- **發音怪？** 設定裡換口音；手機裝了系統的高品質語音套件會更自然。內建 mp3 需要連線下載一次，之後有快取。
- **今天做不完？** 沒做的明天自動排進來，不用補。連續天數跨休息日不會斷。
- **字卡上的「要會拼寫／看得懂就好」可以改嗎？** 點卡片上的徽章即可切換；字庫也能整組切換。
