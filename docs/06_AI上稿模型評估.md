# v2.1 AI 上稿：模型評估與費用

日期：2026-09-11　｜　狀態：評估，v2.0 先由開發者代做，v2.1 才接 API

## 1. AI 在上稿裡做什麼

| 任務 | 輸入 | 輸出 | 每份講義的量 |
|---|---|---|---|
| 產例句與中譯 | 單字、詞性、中文、講義原句（若有） | 一句例句＋中譯，用法筆記 | 40–60 字 |
| 改寫文章 | 原文（僅班級可見） | 同主題原創文章 180–220 字，去品牌 | 1–2 篇 |
| 出理解題 | 改寫後文章 | 3 題四選一＋解析 | 1–2 篇 |
| 逐句中譯 | 改寫後文章 | 每句中譯（句數須與分句規則一致） | 12–17 句／篇 |
| 拆字 | 單字 | 字首／字根／字尾＋中文，不確定就留空 | 40–60 字 |

全部是「文字進、文字出」的單次呼叫，不需要工具呼叫或代理迴圈。輸出用結構化格式（JSON schema）拿，程式直接寫入教材。

## 2. 訂閱與 API 是兩件事

**Claude Pro 訂閱不能直接串進 App。** Pro／Max 是 claude.ai 與 Claude Code 的個人使用方案；App 後端要呼叫模型必須用 Claude API，在 Console（console.anthropic.com）另外開帳號、放儲值，按用量計費。兩者帳單分開。

這對分期的意義：

- **v2.0（開發者代做）**：就是現在的流程，您在 Claude Code 裡用 Pro 訂閱整理講義，不多花錢。
- **v2.1（老師自助）**：Cloud Function 用 API key 呼叫，按量付費。金鑰放在後端，永遠不進 App。

| 模型 | 模型 ID | 輸入 $/百萬 token | 輸出 $/百萬 token | 適合 |
|---|---|---|---|---|

## 4. 一份講義的費用估算

以 2-10 這種規模（60 字、2 篇文章）估：

| 項目 | 輸入 token | 輸出 token |
|---|---|---|
| 例句＋中譯＋筆記 60 字（分 3 批） | 約 6,000 | 約 5,000 |
| 改寫 2 篇＋題目＋逐句中譯 | 約 3,000 | 約 3,500 |
| 拆字 60 字 | 約 1,500 | 約 1,500 |
| 合計 | 約 10,500 | 約 10,000 |

| 模型 | 每份講義 | 換算台幣（以 1:32） | 每週一份、一年 |
|---|---|---|---|
| Opus 5 | 約 $0.30 | 約 10 元 | 約 500 元 |
| Sonnet 5 | 約 $0.12 | 約 4 元 | 約 200 元 |
| 混用（改寫用 Opus、其餘 Sonnet） | 約 $0.18 | 約 6 元 | 約 300 元 |

音檔不用 AI，走現有的免費語音套件在伺服器產，費用是 Cloud Run 的執行時間，一份講義幾秒。

結論：**費用不是決策因素**，一年不到一頓飯。決策因素是品質與由誰付。

## 5. 建議

1. **預設 Opus 5**，全部任務用同一個模型。理由：講義內容會被學生反覆看、被老師署名發布，品質差異比每年 300 元重要；單一模型也讓快取與提示維護簡單。
2. **費用由平台付**（也就是您的 Console 帳戶），老師端不用設定金鑰。老師人數少、用量可預估；等有多位老師再考慮按班級計費。
3. **多方選取不需要現在做**。程式上把「呼叫模型」包成一個介面（輸入任務與資料、輸出 JSON），之後要換或加供應商只改那一層；但第一版只接一家，避免同時維護兩套提示與評估。其他供應商的價格請以各自官網為準，本文件不代為報價。
4. **每個任務都有可驗證的輸出檢查**：例句必須包含該字或其變化形、逐句中譯句數必須等於分句數、題目答案必須在選項內、改寫文章不得出現原文連續 8 字以上、品牌與人名黑名單。不過檢查的結果退回重產一次，再失敗就標給老師看。
5. **老師永遠是最後一關**：AI 產的內容以草稿呈現，老師可改，發布前要按確認。

## 6. 技術做法（v2.1 時實作）

- Cloud Functions（Node／TypeScript）用官方 `@anthropic-ai/sdk`，模型 `claude-opus-5`，`thinking: {type: "adaptive"}`，長輸出用串流。
- 結構化輸出：`output_config.format` 給 JSON schema，程式不用解析自由文字。
- 提示快取：系統提示（格式規則、黑名單、範例）固定放前面，講義內容放後面，同一份講義的多次呼叫共用快取。
- 每次呼叫記錄 `usage`，儀表板可看每份講義的實際花費。
- 金鑰放 Secret Manager；Function 只接受已登入且 role 為 teacher 的呼叫。
