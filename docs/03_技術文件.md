# 技術文件 — 單字練習台 v2

## 1. 架構總覽

結構比照 `stock_ledger`：純 Dart 引擎套件與 Flutter App 分離，App 內 Clean Architecture + Feature-First。

```
vocab_trainer/
├── packages/
│   └── srs_engine/            純 Dart，零 Flutter 依賴，單元測試主戰場
│       ├── lib/src/
│       │   ├── ladder.dart        LADDER、levelOf、nextGap
│       │   ├── grader.dart        applyMark：○△× → 新的 box/ease/due/lapses
│       │   ├── mode.dart          quizType：依 kind/lapses/box/reps 決定作答方式
│       │   ├── queue.dart         buildQueue、同場回籠插入
│       │   └── models.dart        CardProgress、Mark、QuizMode（immutable）
│       └── test/
├── app/
│   ├── lib/
│   │   ├── core/
│   │   │   ├── storage/           Drift database；web.dart / native.dart 條件匯入
│   │   │   ├── io/                備份檔存取；web.dart / native.dart
│   │   │   ├── audio/             TTS、錄音封裝
│   │   │   └── router.dart        GoRouter
│   │   └── features/
│   │       ├── profiles/          學生檔案（domain / data / presentation）
│   │       ├── courses/           教材目錄載入、教材切換
│   │       ├── practice/          今日練習（三段式流程、四種作答）
│   │       ├── library/           字庫
│   │       ├── calendar/          複習行事曆
│   │       ├── reading/           文章（P2）
│   │       ├── settings/
│   │       ├── backup/            匯出、匯入 v1/v2
│   │       └── sync/              Firebase（P1）
│   └── web/                       index.html、manifest、icons
├── data/
│   ├── courses.json
│   └── courses/*.json
├── tools/
│   └── cards2json.dart            八欄文字 → 教材 JSON
├── legacy/index.html              v1（上線 v2 當天搬入）
└── docs/
```

依賴方向：`presentation → domain ← data`，`app → srs_engine`。引擎不知道 Drift、Firebase、Flutter 的存在。

狀態管理 Riverpod 3（原生寫法，不用 codegen，與 line_bento_order 一致）。路由 GoRouter。

## 2. srs_engine API

```dart
/// 間隔階梯（天）
const ladder = [1, 1, 1, 1, 7, 15, 30, 60];

enum Mark { ok, hard, miss }          // ○ △ ×
enum QuizMode { auto, choice, spell, recog }
enum CardKind { production, recognition }   // p / r

@immutable
class CardProgress {
  final String cardId;
  final int box; final double ease; final int reps; final int lapses; final int streak;
  final bool seen; final DateTime? due; final DateTime? last;
  final CardKind kind;
  const CardProgress.fresh(String cardId, {CardKind kind = CardKind.production});
}

/// 目前熟悉度階層 0–8（0 未學、8 畢業）
int levelOf(CardProgress p);

/// 下次間隔天數：max(1, round(ladder[box] * ease / 2.5))
int nextGap(CardProgress p);

/// 套用一次作答，回傳新的進度（純函式，today 由外部注入以便測試）
CardProgress applyMark(CardProgress p, Mark m, DateTime today);

/// 依設定與進度決定作答方式
QuizMode quizType(CardProgress p, QuizMode setting);

/// 建立今日隊列：到期複習（排序、上限）＋ 新字（上限）
List<String> buildQueue({
  required Iterable<CardProgress> all,
  required DateTime today,
  required int goal, required int revCap,
});

/// 同場回籠：回傳插入位置（null 表示不回籠）
int? requeueIndex({required Mark m, required int idx, required int queueLength, required int timesRequeued});
```

所有函式純粹、無 IO、無隨機（干擾項與洗牌在 App 層，引擎只給規則），因此測試不需 mock。

## 3. 資料模型（Drift）

| 表 | 主鍵 | 欄位摘要 |
|---|---|---|
| profiles | id | name, createdAt, lastUsedAt, cloudUid? |
| course_progress | (profileId, courseId) | activeDeckIds(json), lastPracticedAt |
| card_progress | (profileId, courseId, cardId) | box, ease, reps, lapses, streak, seen, due, last, kindOverride?, updatedAt |
| review_log | autoId | profileId, courseId, cardId, date, mark, mode, elapsedMs |
| custom_cards | (profileId, id) | courseId?, en, zh, pos, ex, exz, note, syl, kind, sourceId, updatedAt |
| custom_sources | (profileId, id) | name, file, date, note |
| settings | profileId | goal, revCap, mode, rate, autoSay, artEvery, fontSize, theme |
| article_progress | (profileId, articleId) | reads(json: date, wpm, score), nextDue |

教材內容**不進資料庫**，每次啟動從 `data/courses/*.json` 讀（Web 用 fetch、原生用 assets），以 `courseId + cardId` 與進度 join。

平台分岔：

```dart
// core/storage/db.dart
import 'db_native.dart' if (dart.library.js_interop) 'db_web.dart';
```

Web 用 `drift/wasm.dart`（需 `sqlite3.wasm` 與 `drift_worker.js` 放進 `web/`），原生用 `drift/native.dart`。

## 4. 教材載入

```
CourseCatalogRepository.load()        → 讀 courses.json（快取一次）
CourseRepository.load(courseId)       → 讀單一教材 JSON，解析成 Course(decks, cards, articles, sources)
ActiveCourse (Riverpod)               → 目前 profile 選定的教材
CardWithProgress                      → Course.card × card_progress，practice 用這個
```

教材 JSON 的解析用 `json_serializable` 或手寫 `fromJson`，以 `tools/validate_course.dart` 在 CI 驗證格式。

## 5. 同步（P1）

- `firebase_auth`（Google / anonymous）、`cloud_firestore`（`persistenceEnabled: true`）
- 上傳：`card_progress` 每次寫入後同步寫一筆到 Firestore；離線時由 Firestore SDK 排隊
- 下載：登入或啟動時拉 `updatedAt > lastSyncAt` 的文件合併進 Drift，衝突取 `updatedAt` 較新者
- `review_log` 只上傳不下載合併（append-only，重複無害）
- 匿名帳號認領：另一裝置輸入六位代碼 → Cloud Function 驗證後回傳 custom token → 登入同一 uid

## 6. 語音（P2）

- 朗讀 `flutter_tts`：Web 走 Web Speech，原生走系統 TTS；語速三檔
- 錄音 `record`：Web 產 webm，原生產 m4a；只存記憶體，不落地
- 逐句跟讀：引擎無關，在 `reading` feature 內用句號切句

## 7. 測試策略

| 層 | 工具 | 重點 |
|---|---|---|
| srs_engine | `test` | 每個函式的邊界（box 0/7、ease 上下限、lapses 只在 reps>1 累加）、**v1 對照案例**（從 v1 抽 30 個字的作答序列，驗證 v2 算出相同 box/ease/due） |
| data | `drift` in-memory、`fake_cloud_firestore` | 匯入 v1 備份、合併規則、離線→上線 |
| domain | `test` | use case 組合 |
| presentation | `flutter_test` widget test | 今日練習的三段流程、鍵盤快捷鍵 |
| 教材 | `tools/validate_course.dart` | id 唯一、必填欄位、例句含目標字 |

CI：GitHub Actions，`flutter analyze`（零警告）、`dart test`、`flutter test`、教材驗證，通過才 build web。

## 8. 部署

```bash
flutter build web --release --base-href /vocab-trainer/ --pwa-strategy offline-first
```

- Actions 把 `app/build/web` 推到 `gh-pages` 分支，Pages 來源改成該分支
- `legacy/index.html` 在 v2 上線後保留 30 天，頁首加「新版在這裡」連結
- PWA：`manifest.json` 設好名稱與圖示，手機可加到主畫面
