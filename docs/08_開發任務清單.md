# v2 開發任務清單（給 PM：設計與 RD 的執行順序與里程碑）

日期：2026-09-11　｜　依據：規格書 01–07、線框 21 頁　｜　里程碑（milestone）M0–M5＋v2.1

## 0. 怎麼用這份清單

- **設計走在 RD 前一個里程碑**：RD 做 M1 時，設計交 M2 的 mockup；RD 做 M2 時，設計交 M3、M4。
- 每個里程碑有「完成定義」，達成才進下一個；做不完縮功能，不延時程。
- 角色：**PM**（排程、驗收、決定）、**設計**（Claude Design 產 mockup，PM 審）、**RD**（Flutter、Firebase、Functions）、**內容**（教材包、講義上稿，目前是開發者）、**Joyce**（帳號申請、審核、驗收）。
- 本專案 RD 與內容目前是同一人，設計用 Claude Design；清單仍按角色分，之後分工不用改。

## 1. UI mockup 的產出順序

先做設計系統，再做學生端手機畫面（最多人用、最先上線），再做 RWD 變體，最後老師端桌機。每張 mockup 交付：亮色＋深色、預設／載入中／空／錯誤／離線五種狀態（適用者）、可點區塊標註。
