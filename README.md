# 單字練習台 Vocab Trainer

給高中生準備學測、英檢用的單字練習網頁。單一 HTML 檔，不需安裝、不需後端，手機電腦都能開。
線上版：**https://joyce914apps.github.io/vocab-trainer/**

> 這是一個為真實使用者做的工具，設計原則經過幾輪實際使用後修正而成。
> 下一階段會以 Flutter 重寫（純 Dart 排程引擎 + 多教材 + 多學生 + 跨裝置同步），見「路線圖」。

## 它解決什麼問題

背單字 App 很多，但多數是「翻牌」：看到字、翻面、自評。這種方式對考試幫助有限，因為考試的形狀不是翻牌。
這個工具的做法是：

1. **預習**：在例句裡認識這個字，並手打一次
2. **回想**：例句挖空作答。預設是四選一的選擇題，形狀和學測詞彙題、文意選填相同
3. **標記**：對答案後標 ○△×，程式會建議，但你可以改

## 設計決策

這些是產品的核心，每一條都有理由，改動前請先讀。

| 決策 | 做法 | 為什麼 |
|---|---|---|
| 排程方案可選 | 六個方案：考前混合（預設）、固定遍數法 16 遍、固定遍數法 10 遍、固定遍數法 6–8 遍、衝刺 8 週、衝刺 4 週 | 學習區間與程度不同，適合的階梯不同。三個固定遍數版本取自《遞減背誦法》講義，固定遍數不看對錯；混合與衝刺版走自適應 |
| 預設間隔階梯 | `1, 1, 1, 1, 7, 15, 30, 60` 天 | 前四天連續，取自固定遍數法 6~8 遍版的前段。遺忘曲線最陡的就是頭四天 |
| 後段自適應 | 每個字有自己的難度係數（ease），答錯縮短、答對拉長 | 固定 16 遍不分難易，會把次數浪費在早就會的字上 |
| 目標日反推 | 填目標完成日，算出每日新字至少要幾個，並建議跨度不超過剩餘天數九成的方案 | 讓「每日新字 8」這個數字有意義：學生知道它代表哪一天學完 |
| 新字前段不順延 | 前幾天照日曆天出現，休息日只做這些字（約 5 分鐘）；後段複習才順延到讀書日 | 遺忘曲線走的是日曆天。勾四天讀書日後「前四天連續」會橫跨七天，前段斷掉最傷 |
| 答對的新字當場再看一次 | 第一次答對的新字排到當場最後再出現，不推進階梯 | 對應艾賓浩斯的短間隔與固定遍數法「晚一點再背一次」；原本只有答錯的字會回籠 |
| 拆字與同字根 | 486 個字有人工整理的字首／字根／字尾（predict = pre-（前）＋ dict（說）），預習卡列出同字根的字；字庫可依字根／字尾分組；同字根的新字連著背 | 固定遍數法「一串一串，有邏輯」：一個字根換好幾個字。自動猜字根誤判太多，所以用人工表，只收有把握的 |
| 每日業績 | 今日顯示第 N 個讀書日、連續天數、新字與複習各完成幾個、達成打勾 | 固定遍數法方法最核心的心理機制：每天有業績才有成就感 |
| 同場回籠 | × 的字隔 4 題再考一次，△ 的字排到當場最後再考一次，每字每場最多兩次 | 剛忘掉的東西要在同一次補回來，不能等明天。這是艾賓浩斯裡最常被省略的一段 |
| 預設選擇題 | 四種作答方式：自動／選擇／拼寫／只求認得 | 學測英文 100 分裡只有中譯英 8 分與作文 20 分需要拼得出來 |
| 拼寫的時機 | 標「要會拼寫」的字，第 4 階起每三次考一次；退步兩次以上的字一律拼寫 | 拼寫最慢也最紮實，留給需要確認與頑固的字 |
| 新字與複習分開計額 | 預設新字 8、複習 60 | 前四天連續的字重看很快，不該和新字搶同一個額度 |
| 讀書日 | 勾選一週哪幾天讀書（預設二三四五）。複習到期日落在休息日自動順延到下一個讀書日 | 複習可以等讀書日；每週新字量 = 每日新字 × 讀書日天數 |
| P / R 標記 | 每個字標「要會拼寫」或「看得懂就好」 | 吸收自龍騰七格背誦版的 Words for Production / Recognition 概念 |

排程相關程式碼集中在 `PLANS`、`applyRule`、`nextGap`、`quizType`、`snap`、`buildQueue`、`doMark`，約 120 行。純函式部分有測試：

```
TZ=Asia/Taipei node tests/scheduler.test.js   # 排程、讀書日、方案
node tests/morph.test.js                       # 拆字表格式與同字根查詢
```

### 與固定遍數法、艾賓浩斯的對照

| 面向 | 固定遍數法 | 艾賓浩斯經典表 | 這個工具 |
|---|---|---|---|
| 對錯 | 不看，固定遍數 | 不看 | 固定遍數法方案不看；混合與衝刺方案 ○△× 改變間隔 |
| 前段 | 連續 4–5 天 | 同日短間隔，再 1、2、4、7 天 | 連續 4–5 天，答對新字當天再看一次 |
| 中後段 | 7,7 / 30,30 | 7、15、30 | 依方案 |
| 每天 | 一定每天 | 一定每天 | 前段照日曆天，後段順延到讀書日 |

## 新增單字

### 方式一：在網頁裡貼上（存在該裝置的瀏覽器）

到「貼上字卡」分頁，一行一張卡，欄位用 `|` 隔開：

```
單字 | 中文 | 詞性 | 英文例句 | 例句中譯 | 用法筆記 | 音節拆解 | P或R
```

- 第 7 欄放音節拆解（例如 `me-mo-ra-ble`）
- 第 8 欄 P＝要會拼寫、R＝看得懂就好
- 第 3 欄之後都可省略

把講義 PDF 的文字丟給 AI，請它回傳這個格式，貼進去即可。掃描檔沒有文字層，複製不出來。

### 方式三：貼文章「找出生字」

把文章貼進「貼上字卡」分頁按「找出生字」：

- **字庫已有的字**標「未學／第 N 遍／已畢業」，勾選未學的會**排到下一批新字**，它們本來就有拆字、音節與四國 mp3
- **新字**用內建字典（`data/dict.json`，ECDICT 開源字典的常用字子集約 1.8 萬字、繁體）自動帶入中文與詞性，例句就是文章裡那一句；字典沒有的按「線上查」（MyMemory 免費翻譯），例句中譯也可一鍵翻
- 新建的字卡沒有內建 mp3，先用瀏覽器語音；之後把備份給開發者跑一次 `tools/gen_audio.py` 就能補上

### 方式二：寫進檔案（所有人都會拿到）

在 `index.html` 的 `EXTRA` 陣列加一個字組，並在 `SRC` 加一筆教材來源。每個字的格式：

```js
["單字","詞性","中文","英文例句","例句中譯","例句中的變化形","用法筆記"]
```

已存在的進度不受影響，新字組會在下次開啟時自動補進去。

## 音檔

`audio/` 目錄放內建 mp3：單字、例句、五篇文章（整篇與逐句），各有美、英、澳、加四國口音，由 `tools/gen_audio.py` 用微軟 Edge 神經網路語音產生，比瀏覽器內建語音自然得多。播放順序：文章自己上傳的音檔 → 內建 mp3 → 瀏覽器語音（離線或沒有音檔時）。

新增單字或文章後重新產生缺少的音檔：

```
pip3 install edge-tts          # 需要網路；有 ffmpeg 會順便壓小檔案
python3 tools/gen_audio.py     # 已存在的略過
```

整篇文章播放時**逐字反白**（當前字螢光、當前句淡底、自動捲動），時間點來自產生音檔時記下的每字起訖秒數（`audio/a/<id>_<accent>.words.json`），與內文逐字對齊。逐句跟讀時反白當前句。

文章頁可以「用自己的音檔」，例如老師的錄音。它存在那台裝置的瀏覽器（IndexedDB），換裝置要再上傳一次，優先於內建音檔。

## 進度與備份

進度存在**這台裝置的這個瀏覽器**的 localStorage，換裝置不會自動同步。
「設定與備份」分頁可以下載備份檔（JSON）或產生備份文字，到新裝置還原。

備份格式：

```json
{ "format": "vocab-trainer-backup", "version": 1, "exportedAt": "...", "stats": {...}, "state": {...} }
```

Flutter 版會直接讀這個格式匯入舊進度。

## 本機執行

直接用瀏覽器開 `index.html` 即可，不需要任何伺服器。
